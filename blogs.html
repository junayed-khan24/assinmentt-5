Question-2: What is the difference between innerHTML, innerText, and textContent ?

In JavaScript, innerHTML, innerText, and textContent are used to access or update the content inside an HTML element — but they behave differently.


Question-3: What is event delegation in the DOM?

Event delegation in the DOM is a technique where instead of adding event listeners to multiple child elements, you add one event listener to their common parent and handle the event using event bubbling.


Question-4: What is event bubbling in the DOM?

Event bubbling is the default behavior in the DOM where an event starts at the deepest (most specific) element and then bubbles up to its parent elements, one by one, until it reaches the document level.


Question-5: How do you create, add, and remove elements using JavaScript?

You create elements using createElement(), add them with appendChild(), prepend(), or insertBefore(), and remove them using remove() or removeChild() from their parent element.
